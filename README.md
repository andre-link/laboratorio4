# AcopioGT - Laboratorio 4: Polimorfismo (CC2008)

## Requisitos
- Java Development Kit (JDK) 11 o superior.

## Instrucciones para compilar y ejecutar
1. Abra una terminal en la carpeta donde se encuentran los archivos `.java`.
2. Compile todos los archivos con el comando:
   ```bash
   javac *.java
   ```
3. Ejecute el programa principal con el comando:
   ```bash
   java Main
   ```
